# 벡터와 좌표계 

### 벡터의 정의와 연산 
>▏ 힘·속도·가속도·위치·회전축이 모두 벡터입니다. n개의 성분을 세로로 배열한 열벡터로 적습니다.<br>
>▏ 덧셈과 실수배는 성분별로 계산하고, 크기(노름)는 피타고라스 정리의 n차원 확장입니다.

### 벡터 연산의 기하학
>▏ a+b 는 두 벡터를 이웃한 변으로 하는 평행사변형의 대각선입니다.<br>
>▏ 실수배 k·a 는 방향은 유지(또는 반전)하고 크기만 k배 합니다.

### 벡터공간/부분공간/기저/차원
>▏ (x, y, z) 라는 숫자는 '어떤 기준 축(기저)에서 쟀는가'에 따라 완전히 달라집니다.<br>
>▏ 로봇의 base·camera·LiDAR 좌표계는 서로 다른 기저의 선택이고, 좌표 변환이란 기저를 바꿔 읽는 일입니다.
